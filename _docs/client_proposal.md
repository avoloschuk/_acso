# Комерційна пропозиція: Оновлення веб-сайту ВГО «АСН»

## 1. Що буде робитися
Ми розробимо сучасний, швидкий та адаптивний веб-сайт для ВГО «Асоціація сприяння самоорганізації населення», який повністю відповідатиме затвердженому брендбуку. 

Новий сайт отримає структуровані розділи для аналітики, бібліотеки та блогів ресурсних центрів. Головна мета — створити не просто "новинний портал", а солідний цифровий офіс серйозної громадської організації, який викликатиме довіру в донорів, партнерів та громадян. Усі старі матеріали та статті будуть перенесені на нову платформу.

## 2. Як буде робитися
Процес розробки базуватиметься на принципах надійності та збереження даних:

*   **Дизайн та Верстка:** Спочатку створюється чистий HTML/CSS макет (на базі ваших фірмових кольорів та шрифтів `e-Ukraine`), який ідеально адаптується під мобільні телефони та планшети.
*   **Тонка інтеграція:** Замість встановлення важких плагінів-конструкторів, ми інтегруємо наш дизайн безпосередньо у нативні блоки WordPress (Full Site Editing). Це гарантує максимальну продуктивність.
*   **Автоматизована міграція контенту:** Ми напишемо спеціальні скрипти (ETL), які безпечно "витягнуть" вашу базу даних зі старого сайту, очистять її від застарілих шорткодів та завантажать у нову систему. 
*   **Автоматизоване тестування (Playwright):** Для нас критично важливо, щоб новий сайт працював без багів. Щоб переконатися, що міграція пройшла успішно, ми використаємо систему Playwright. Вона автоматично просканує всі статті за останні півроку, зробить візуальне порівняння старого та нового сайту і перевірить відсутність "битих" посилань (404).

## 3. На чому буде робитися (Технологічний стек)
*   **Платформа:** Остання версія **WordPress**. Ми свідомо обрали класичну архітектуру WordPress замість експериментальних Headless-систем, щоб ваші контент-менеджери мали звичний, зручний та зрозумілий інтерфейс для публікації статей.
*   **Максимальна зворотна сумісність (Backward Compatibility):** Ми повністю відмовляємося від важких надбудов типу *Elementor* чи *WPBakery*. Сайт буде побудований на нативному редакторі **Gutenberg**. Це гарантує, що при майбутніх оновленнях ядра WordPress або стандартних плагінів, ваш сайт ніколи не "зламається" і працюватиме стабільно роками.
*   **Плагіни:** Використовуватимуться виключно перевірені часом стандарти ринку (наприклад, для SEO, багатомовності та розширених полів), щоб забезпечити стабільність та легкість адміністрування.
