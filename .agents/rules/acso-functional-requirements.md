# Функціональні вимоги (ТЗ + структура)

## Меню та розділи
**ТЗ (плоске меню):** Головна, Про нас, Місцева демократія, Аналітика, Бібліотека, Новини Асоціації, **Мережа ресурсних центрів** (не «РЦ»), Блог партнерів.

**Прототип / implementation_plan:** Бібліотека під «Аналітика ▾», блог під «Мережа ▾» — узгодити з замовником перед фінальним меню.

## Сторінки (коротко)
- **Головна:** hero, про АСН, напрями, хайлайти/останні матеріали (auto + manual pick), блок мережі РЦ, footer. Референс: `prototype/index.html`.
- **Про нас:** місія, історія, напрями, команда (structured fields), партнери, звіти PDF, контакти.
- **Місцева демократія:** landing з тематичними блоками (редаговані, reorder, hide/show).
- **Аналітика / Бібліотека:** архіви, пошук, фільтр за напрямом, pagination/load more; картки та single з обкладинкою, PDF, share, related.
- **Новини АСН:** архів + single (галерея, відео, файли).
- **Мережа РЦ:** ~16 центрів, **інтерактивна карта**, сторінки центрів, новини мережі, фільтр новин по РЦ.
- **Блог партнерів:** мультиавтор; див. ролі нижче.

## Мультиблог / ролі РЦ
- Редактор РЦ — лише свої новини; не чіпає меню, тему, плагіни, інших користувачів.
- Адмін — все; може вимкнути self-publish для редактора.
- Матеріали партнерів — редактор може лише **на премодерацію** (за ТЗ).
- Реалізація: Multisite **або** single site + CPT + author/meta РЦ — погодити з замовником.
- Зберігати автора та історію редагувань.

## Двомовність (UA + EN)
- Перемикач у header; окремі меню; linked translations; hreflang; коректні URL.
- Якщо перекладу немає — **не** вести на 404 (приховати/ disabled switch).
- Machine translate — бажано, не обов’язково.

## Header / footer
- Header: logo, menu, langs, search, Facebook, mobile menu.
- Footer: про АСН, контакти, соцмережі, карта сайту, **донорський дисклеймер**, copyright — редаговані з адмінки.

## Форми
- Contact form: email, success message, antispam, GDPR consent, UA/EN; отримувачів змінює адмін без коду.

## Продуктивність (приймання)
- PageSpeed (або аналог): **≥80 mobile**, **≥90 desktop** на ключових шаблонах (за можливості хостингу).
- Мінімум плагінів, оптимізація зображень, lazy load, кеш (host/plugin), без зайвих third-party scripts.

## Безпека
- SSL, захист admin, antispam, limit login attempts, individual accounts, **2FA для адмінів** (рекомендовано), оновлення WP/теми/плагінів, role separation, без nulled software.

## Backup
- Auto backup: DB, uploads, theme, plugins, config; копії off-server; інструкція restore для адміна.

## Навчання
Після запуску — інструктаж: сторінки, новини, аналітика, бібліотека, переклади, напрями, головна, користувачі/ролі, РЦ, backup.

## Дизайн (тон)
Мінімалізм, аналітичний центр, брендбук; без «мультика» та зайвої декорації. Токени: accent `#e95029`, dark `#12162a`, gray `#d3d4d8`, light `#e5e3e8`, шрифт **e-Ukraine**, scale ~**1.68** (див. `prototype/style.css`, `design_tokens.css`).
